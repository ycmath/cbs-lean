# MC G0 Two-Generator Exactness and Converse Conjecture v0.1

## Theorem-backed direction

For positive widths `p,h` and arbitrary target width `q`, define

\[
I_{p\to q}(x)=\left\lceil\frac{qx}{p}\right\rceil.
\]

If

\[
h=a p+b q\qquad(a,b\in\mathbb N),
\]

then

\[
I_{h\to q}(I_{p\to h}(x))=I_{p\to q}(x)
\quad\text{for every }x.
\]

This is formalized in `CbsLean/MagicCapacitySemigroup.lean` as
`insertionComposite_eq_direct_of_twoGenerator`.  It strictly generalizes the
initial divisor-chain sufficient condition: the middle width may be a mixed
nonnegative combination of both endpoint widths.

## Open converse

The next exact arithmetic target is:

> For positive `p,h,q`, exact equality for every integer index `x` holds if and
> only if `h` belongs to the additive semigroup generated by `p` and `q`.

Formally, the unproved direction is

\[
\bigl(\forall x,\ I_{h\to q}(I_{p\to h}(x))=I_{p\to q}(x)\bigr)
\Longrightarrow
\exists a,b\in\mathbb N:\ h=ap+bq.
\]

**Status:** exploratory conjecture; not a repository theorem and not a novelty
claim.  Literature search and a separately frozen finite-grid audit are still
required before positioning.

## Why it matters for magic capacity

If the converse is true, globally carry-free one-block insertion has a complete
arithmetic certificate: middle widths are exactly the lattice points of a
2-generator numerical semigroup.  Magic-capacity search would then reduce from
an unrestricted width scan to semigroup membership plus residue-local checks
for state/transition shell quantities.
